Viewing code scanning metrics for pull requests

Monitor how CodeQL and AI Scan perform in pull requests across your organizations to identify repositories where you may need to take action.

Viewing code scanning pull request metrics for an organization

  1. On GitHub, navigate to the main page of the organization.

  2. Under your organization name, click the Security and quality tab.

  3. In the sidebar, under "Insights", click Code scanning on pull requests.

  4. Select the CodeQL or AI Scan tab.

  5. Optionally, use the date picker to set the time range. The date picker filters data based on when the pull request alerts or findings were created.

  6. Optionally, apply filters in the search box at the top of the page.

  7. Alternatively, you can open the advanced filter dialog:

    • At the top of the page, next to the search box, click Filter.
    • Click Add a filter, then select a filter from the dropdown menu.
    • To search for repositories matching the selected filter, fill out the available fields for that filter, then click Apply. You can repeat this process to add as many filters as you would like to your search.
    • Optionally, to remove a filter from your search, click Filter. In the row of the filter you want to remove, click , then click Apply.

  8. On the CodeQL tab, you can use the Export CSV button to download a CSV file of the displayed data. CSV export is not yet available for the AI Scan tab. For more information, see Exporting data from security overview.

Viewing code scanning pull request metrics for your enterprise

You can also view code scanning metrics for pull requests across organizations in your enterprise.

  1. Navigate to GitHub Enterprise Cloud.

  2. In the top-right corner of GitHub, click your profile picture.

  3. Depending on your environment, click Enterprise, or click Enterprises then click the enterprise you want to view.

  4. At the top of the page, click the Security and quality tab.

  5. In the sidebar, under "Insights", click Code scanning on pull requests.

  6. Select the CodeQL or AI Scan tab.

  7. Optionally, use the date picker or filters to limit the displayed data.

Tip

You can use the owner filter in the search field to filter the data by organization. For more information, see Filtering alerts in security overview.
