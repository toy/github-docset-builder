Enabling security features in your trial

Apply Secret Protection and Code Security to a sample of repositories so your team can evaluate the features during your trial.

This article assumes that you have planned and started a trial of GitHub Advanced Security. For more information, see Planning a trial of GitHub Advanced Security.

Use this article to quickly enable the security features you want to trial as a starting point for deeper exploration. Results should appear soon for your trial repositories, and you can fine-tune the configuration later.

Enable security features with quick setup

Use quick setup to enable security features for a sample of repositories that your team understands well. This makes it easier to judge whether the results and developer experience meet the goals you defined for the trial.

  1. In the upper-right corner of GitHub, click your profile picture, then click Your organizations.
  2. Next to the organization, click Settings.
  3. In the "Security" section of the sidebar, select Advanced Security, then click Configurations.
  4. Click New configuration.
  5. In the setup dialog, review the default settings and the repositories selected for the trial, and make any necessary adjustments.
  6. Click Review to see a summary of your configuration, then click Save and enable to apply it.

Next steps

Now that you have enabled the security features you want to test, you are ready to look more deeply into how GitHub Secret Protection and GitHub Code Security protect your code.

  1. Review and assess secret scanning alerts. See Viewing and filtering alerts from secret scanning.
  2. Review and assess code scanning alerts. See Assessing code scanning alerts for your repository.
